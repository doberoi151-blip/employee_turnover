# Employee Turnover Prediction

This project predicts whether an employee is likely to leave the company using Machine Learning.

## Project Overview
- Data preprocessing
- Feature selection
- Model training
- Model evaluation

## Models Used
- Logistic Regression
- Lasso

## Results
- Baseline Accuracy: 85.93%
- Lasso Accuracy: 87.04%
